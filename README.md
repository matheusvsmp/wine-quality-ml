# 🍷 Wine Quality ML — Análise da Qualidade de Vinhos

Projeto de Machine Learning aplicado à análise da qualidade de vinhos tintos, usando o
**Wine Quality Dataset** (UCI Machine Learning Repository — `winequality-red.csv`).
Atividade Final da disciplina de Machine Learning — Unifor.

## 🎯 Objetivos

1. Prever se um vinho tem **qualidade baixa ou alta** a partir de suas características físico-químicas.
2. Descobrir se existem **grupos naturais** de vinhos semelhantes (K-Means).
3. Representar os vinhos em **2 dimensões** (PCA) e observar padrões.

## 🛠️ Tecnologias

Python · Pandas · Matplotlib · Scikit-learn · Jupyter / Google Colab
